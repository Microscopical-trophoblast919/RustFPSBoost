3.  Select Manage settings under the Virus & threat protection settings menu.

5.  If you use third-party antivirus software, disable it through its interface.

If the software does not behave as expected, review these common fixes:

If you see a black screen: Close the game and the tool. Update your graphics card drivers using the software provided by your hardware manufacturer. Restart your computer and try again.

If the game does not show performance gains: Check if the application shows a status of Active. If the status is Inactive, click the Start button again before loading the game.

Do I need to leave the tool open?
You should leave the application running in the background to maintain the performance settings while you play.

Does it work on laptops?
Yes. The software works on any computer with a Windows operating system regardless of whether it is a desktop or a laptop.

Will it harm my hardware?
No. The application safely adjusts system parameters to prioritize gaming performance. It does not overclock your hardware or increase heat production beyond normal gaming limits.
